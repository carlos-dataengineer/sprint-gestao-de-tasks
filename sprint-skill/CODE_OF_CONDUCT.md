# Código de conduta

Quero manter este projeto aberto, colaborativo e respeitoso.

Ao participar, espero que todas as pessoas:

- Tratem as outras com respeito e educação.
- Recebam opiniões diferentes com abertura.
- Façam críticas sobre ideias e implementações, sem ataques pessoais.
- Evitem linguagem ofensiva, discriminação, assédio e exposição de dados privados.
- Ajudem a manter as discussões objetivas e relacionadas ao projeto.

Comportamentos que não respeitem essas orientações podem levar à remoção de comentários ou à restrição de participação no projeto.
